# Worldtimecalc

世界の都市間の時差を計算するWebアプリです。
基準となる都市・日付・時刻を指定すると、選んだ他の都市での年月日・曜日・時刻を表示します。

## 主な機能

- 世界の主要都市（約80都市）から、基準都市と知りたい都市（最大5都市）を選べます。都市は地域別に分類しています。
- 各都市について、次の情報を表示します。
  - 年月日・曜日・時刻
  - 基準都市との時差（例：+8時間、−13時間30分）
  - 基準の日付とのずれ（前日／同日／翌日）
  - UTCとの差（例：UTC+9）と、サマータイム中かどうか
- 知りたい都市の日付・時刻を変えると、基準都市と他の都市も連動して変わります。
- サマータイムは自動で反映されます。30分・45分単位の時差の都市（インド、ネパールなど）にも対応しています。
- 基準都市と知りたい都市のリストはブラウザに保存され、次に開いたときに復元されます。日付と時刻は保存せず、開いたときの現在時刻になります。
- スマホの画面幅でも使えます。

## 使い方

インストールやビルドは不要です。`index.html` をブラウザで開くだけで動きます。

1. `index.html` を手元に用意します。
   - Gitを使う場合：
     ```sh
     git clone https://github.com/rihipapa/Worldtimecalc.git
     ```
   - Gitを使わない場合：GitHubのリポジトリページで「Code」→「Download ZIP」を選び、ダウンロードしたZIPファイルを展開します。
2. `index.html` をブラウザで開きます。次のどちらの方法でも開けます。
   - エクスプローラー（Macの場合はFinder）で `index.html` をダブルクリックする
   - 開いているブラウザのウィンドウに `index.html` をドラッグ＆ドロップする
3. 「基準」で都市・日付・時刻を指定し、「都市を追加」で知りたい都市を追加します。

Chrome、Edge、Firefox、Safariなど、最新のブラウザで動作します。

## 技術構成

- HTML・CSS・JavaScriptだけで書いた1つのファイル（`index.html`）です。外部ライブラリは使っていません。
- 時刻の変換には、ブラウザ標準のIntl APIとIANAタイムゾーン名（例：`Asia/Tokyo`）を使っています。
- 設定はブラウザのlocalStorageに保存します。別のブラウザやパソコンには引き継がれません。
